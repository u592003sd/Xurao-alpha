# Xurao-α MCU Developement Board

## Overview
- A minimalist Development Board design for STM32 F0 & L0 series TSSOP20 MCUs.
- Low cost ARM Cortex M0/M0+ MCU support

## Features
- Supports USB & SWD connection
- Powers up from Host USB port.
